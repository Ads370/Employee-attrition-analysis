# Employee Attrition Analysis

## Overview
End-to-end machine learning project analysing the drivers of employee 
attrition using the IBM HR Analytics dataset. The project covers 
exploratory data analysis, feature engineering, and classification 
modelling, with model interpretability addressed through SHAP values.

## Tasks Covered
- Exploratory Data Analysis (EDA)
- Feature Engineering and Preprocessing
- Classification Modelling (Logistic Regression, Random Forest, 
Gradient Boosting, LightGBM)
- Model Interpretability with SHAP values

## Results
LightGBM achieved the best performance. SHAP analysis identified 
the key drivers of attrition including overtime, job level, and 
monthly income.

## Tools & Libraries
Python, pandas, scikit-learn, LightGBM, SHAP, seaborn, matplotlib

## Dataset
[IBM HR Analytics Dataset](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset) via Kaggle
